2. Here are the proejct details i came up with:
Project idea for 5391: a web app where you ask questions in plain English, an LLM converts them to SQL, and a validation layer checks every query before it runs thus blocking destructive statements and injection patterns, logging every decision. It covers frontend, backend, database, and security, and demos well since you can watch a bad query get blocked in real time.Why this one: LLM-to-database tools are already in production and already have CVEs. Existing defenses either require retraining the model or are heavyweight generic guardrails that aren't SQL-aware. A transparent, SQL-specific check layer that works with any LLM fills that gap, and it's testable, so the evaluation work for the course is real rather than made up

- Topic: QueryGuard. An AI writes SQL from your question. A safety gate checks it first.
- Stack: Python + Flask + SQLite. Free choice was allowed; nothing to install on your side.
